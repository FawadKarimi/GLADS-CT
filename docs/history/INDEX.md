# Historical documentation

We keep this archive to preserve the project's development history while providing one current repository README.

- `PHASE0.md` and `PHASE1.md`: earlier baseline infrastructure instructions.
- `PUBLICATION-OVERVIEW-20261022.md`: the first public source/evidence README.
- `R50-SOURCE-OVERVIEW-20261022.md`: the former snapshot README.
- `PUBLICATION-LEDGER-20261022.json`: the previous publication ledger.
- `DOCUMENTATION-MOVES.json`: exact old/new paths and hashes.

These files are preserved byte for byte. Their relative links and command paths refer to their original locations. For that original context, read [commit 3cf719e9](https://github.com/FawadKarimi/GLADS-CT/tree/3cf719e932bc882ecf9045c6500c6a8738a1dd66). Use the root README and current source guide for navigation today. Historical instructions are not current execution authorizations.
